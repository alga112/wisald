# وصال — منصة ربط الاحتياج الصحي

نموذج أولي لهاكاثون تنمية ثون: يربط المستشفيات المحتاجة بالجمعيات الخيرية القادرة على تلبية احتياجها، مع اتفاقية تعاون إلكترونية، ومطابقة ذكية، وتتبع لوجستي للشحنات، وحماية للبيانات.

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages على المستودع.

## ربط قاعدة البيانات (Google Sheets)
1. افتح Google Sheet جديدًا (أو الشيت الحالي الخاص بالزوار).
2. من القائمة: **الإضافات ← Apps Script**، واحذف أي كود موجود، والصق محتوى `apps-script/Code.gs`، ثم احفظ.
3. اختر الدالة `setup` واضغط **تشغيل** مرة واحدة، ووافق على الصلاحيات (تنشئ أوراق: الجهات، الطلبات، سجل الوصول، الزوار).
4. **نشر ← نشر جديد ← تطبيق ويب**: «التنفيذ بصفتي»، و«من لديه حق الوصول: أي شخص». انسخ رابط `/exec`.
5. ضع الرابط في `index.html` في السطر `const APPS_SCRIPT_URL="..."`.
   - إذا عدّلت مشروع Apps Script الحالي نفسه: **نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد**، ويبقى الرابط كما هو.

عند أول فتح للموقع تُعبّأ الشيت تلقائيًا بالبيانات التجريبية. لإعادة ضبطها قبل العرض افتح الموقع مع `?reset=1` في آخر الرابط.
في أسفل كل صفحة مؤشر: 🟢 متصل بقاعدة البيانات، أو ⚪ وضع محلي (إذا لم يعمل الربط).

> ملاحظة: رابط Apps Script العام يسمح لمن يعرفه بقراءة بيانات النموذج. هذا مناسب لنموذج تجريبي ببيانات توضيحية فقط، والنسخة الإنتاجية تحتاج خادمًا بصلاحيات وتسجيل دخول.

## الخرائط
- خرائط حقيقية عبر Leaflet وOpenStreetMap (CARTO).
- مسار الطريق الفعلي والمسافة عبر خدمة OSRM المفتوحة، مع مسار بديل عند توفره.
- إذا تعذّر تحميل الخريطة (بدون إنترنت) يعرض الموقع خريطة مبسّطة تلقائيًا.
